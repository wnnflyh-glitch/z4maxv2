# Cloning System

#### Overview

Cloning System เป็นระบบในเกม **Zone4** ที่ออกแบบมาเพื่อแยก **Appearance (รูปลักษณ์)** ออกจาก **Stat (ค่าสเตตัส)** ของไอเทมเครื่องแต่งกาย ผู้เล่นสามารถนำค่าพลังจากไอเทมหนึ่งไปใช้กับอีกไอเทมหนึ่งได้ ทำให้สามารถเลือกใส่ชุดที่สวยงามพร้อมกับค่าสเตตัสที่ดีที่สุดได้ในเวลาเดียวกัน ระบบนี้ช่วยเพิ่มความยืดหยุ่นในการปรับแต่งตัวละคร (Customization)

#### Step 4 – Execute Cloning

การ Cloning มี 3 ผลลัพธ์ ด้วยกัน

| Result           | Description           |
| ---------------- | --------------------- |
| Success          | Clone สำเร็จ          |
| No Change        | ไม่เกิดการเปลี่ยนแปลง |
| Failure (Poison) | ไอเทมติดสถานะพิษ      |
