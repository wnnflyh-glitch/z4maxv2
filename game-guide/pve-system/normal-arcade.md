# Normal Arcade

### Overview

**Normal Arcade** เป็นโหมด **PvE แบบ Story Progression** ของเกม Zone4 ที่ผู้เล่นจะต้องต่อสู้กับศัตรู AI ภายในด่านต่าง ๆ เพื่อดำเนินเนื้อเรื่องและปลดล็อกพื้นที่ใหม่

โหมดนี้มีลักษณะเป็น

> **Stage-based PvE Mode**

ผู้เล่นจะต้อง

* ต่อสู้กับศัตรูในแต่ละพื้นที่
* เคลียร์ wave ของ monster
* กำจัด boss ของด่าน

เมื่อผ่านด่านแล้วจะสามารถลุ้นรับรางวัลพิเศษได้

## Reward System

เมื่อผู้เล่นเคลียร์ Arcade จะได้รับ

| Reward   | Description       |
| -------- | ----------------- |
| EXP      | เพิ่มเลเวลตัวละคร |
| Gold     | เงินในเกม         |
| Item     | อุปกรณ์           |
| Material | วัตถุดิบ          |

Boss ของแต่ละด่านมักมี

```
Rare item drop
```
