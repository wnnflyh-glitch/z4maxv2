# Equipment Tier

Zone4 ใช้ระบบ **Item Tier / Grade**

เพื่อกำหนดความหายากและพลังของอุปกรณ์

โครงสร้าง Tier โดยทั่วไป

| Tier     | Color  | Description        |
| -------- | ------ | ------------------ |
| Low      | Black  | ไอเท็มระดับต่ำ     |
| Normal   | Gray   | ไอเท็มระดับพื้นฐาน |
| High     | Green  | ไอเท็มระดับสูง     |
| Unique   | Blue   | ไอเท็มระดับพิเศษ   |
| Rare     | Yellow | ไอเท็มระดับสูง     |
| Legend   | Orange | ไอเท็มระดับตำนาน   |
| Ultimate | Pink   | ไอเท็มระดับสุดยอด  |

Tier ส่งผลต่อ

* Stats base
* Visual effect
