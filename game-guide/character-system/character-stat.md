# Character Stat

## Attack Status

Attack ถูกแยกเป็น **5 ประเภท**

| Type           | ความหมาย                       |
| -------------- | ------------------------------ |
| Hit Attack     | ค่าการโจมตีปกติ                |
| Grip Attack    | ค่าการโจมตีจับ / throw         |
| Team Attack    | ค่าการโจมตี แบบทีม             |
| Double Attack  | ค่าการโจมตี ศัตรูสองคนพร้อมกัน |
| Special Attack | ค่าการโจมตีด้วยสกิลพิเศษ       |

## Defence Status

Defense ถูกแยกเป็น **5 ประเภท**

| Type            | ความหมาย                           |
| --------------- | ---------------------------------- |
| Hit Defence     | ค่าป้องกัน การโจมตีปกติ            |
| Grip Defence    | ค่าป้องกัน การโจมตีจับ / throw     |
| Team Defence    | ค่าป้องกันโจมตี การโจมตีแบบทีม     |
| Double Defence  | ค่าป้องกันโจมตี ศัตรูสองคนพร้อมกัน |
| Special Defence | ค่าป้องกันโจมตีด้วยสกิลพิเศษ       |

## Critical Status

Critical ถูกแยกเป็น **2 ประเภท**

| Stat            | ความหมาย                          |
| --------------- | --------------------------------- |
| Critical Rate   | % โอกาศในการเกิด Critical         |
| Critical Damage | % Damage Bonus เมื่อเกิด Critical |

## Point Status

Point ถูกแยกเป็น **2 ประเภท**

| Stat               | ความหมาย     |
| ------------------ | ------------ |
| Health Point (HP)  | ค่าพลังชีวิต |
| Special Point (SP) | ค่าพลังพิเศษ |
