# Character Roster

ในระบบปัจจุบันของ Zone4 มี **6 ตัวละครหลัก (Base Characters)** ที่ผู้เล่นสามารถเลือกใช้เป็น Avatar ในเกม โดยตัวละครเหล่านี้เป็นสมาชิกของกลุ่มนักสู้ที่เกี่ยวข้องกับองค์กร **Saints Association** และการแข่งขัน **FFC (Fight Festival Championship)** ซึ่งเป็นศูนย์กลางของเนื้อเรื่องเกม



## 1. Wells

**Basic Profile**

| Attribute  | Value                  |
| ---------- | ---------------------- |
| Age        | 25                     |
| Gender     | Male                   |
| Occupation | Toothbrush Salesperson |
| Hobby      | Beat Boxing            |
| Blood Type | O                      |

**Character Background**

Wells เป็นชายหนุ่มรูปร่างแข็งแรงที่ดูเหมือนนักเลง แต่จริง ๆ แล้วมีนิสัยใจดีและไม่ชอบการต่อสู้มากนัก วันหนึ่งเขาช่วย **Nicky** จากอันตรายและตกหลุมรักเธอทันที หลังจากรู้ว่า Nicky ชอบผู้ชายที่แข็งแกร่ง เขาจึงเริ่มฝึกศิลปะการต่อสู้และเข้าร่วม **Saints Association** เพื่อพิสูจน์ตัวเอง

**Character Identity**

* ตัวละครหลักของเกม
* เป็นจุดศูนย์กลางของเรื่องราว
* มีความสมดุลในการต่อสู้

***

## 2. Ray

**Basic Profile**

| Attribute  | Value                  |
| ---------- | ---------------------- |
| Age        | 21                     |
| Gender     | Male                   |
| Occupation | Extreme Sports Athlete |
| Hobby      | Extreme Sports         |
| Blood Type | AB                     |

**Character Background**

Ray เป็นนักกีฬาสุดเย็นชาและเป็นลูกศิษย์ของนักสู้ระดับตำนาน **Roddy Heart** หลังจากอาจารย์ของเขาหายตัวไป Ray จึงพยายามสานต่อความฝันของ Roddy ในการฟื้นฟู **Saints Association** และคืนชื่อเสียงให้กับการแข่งขัน FFC

**Character Identity**

* นักสู้ที่มีความเป็นผู้นำ
* บุคลิกสงบ เยือกเย็น
* มีความสัมพันธ์พิเศษกับ Sera

***

## 3. Joony

**Basic Profile**

| Attribute  | Value                        |
| ---------- | ---------------------------- |
| Age        | 17                           |
| Gender     | Male                         |
| Occupation | High School Student / Hacker |
| Hobby      | Skateboarding                |
| Blood Type | B                            |

**Character Background**

Joony เป็นลูกชายของ **Davark** นักสู้ระดับอัจฉริยะที่เคยต่อสู้กับองค์กร By-X เพียงลำพัง เขาเติบโตมาพร้อมกับแรงกดดันจากชื่อเสียงของพ่อ และต้องการพิสูจน์ว่าตนเองสามารถเป็นนักสู้ที่ยิ่งใหญ่กว่าตำนานได้

**Character Identity**

* นักสู้วัยรุ่นอัจฉริยะ
* มีความทะเยอทะยานสูง
* มีความขัดแย้งกับพ่อ

***

## 4. Lilru

**Basic Profile**

| Attribute  | Value   |
| ---------- | ------- |
| Age        | 24      |
| Gender     | Female  |
| Occupation | Chef    |
| Hobby      | Cooking |
| Blood Type | O       |

**Character Background**

Lilru เป็นเชฟสาวที่เปิดร้านอาหารของตนเอง เธอแอบชอบ Wells แต่เมื่อ Wells ไปหลงรัก Nicky เธอจึงเริ่มฝึกการต่อสู้เพื่อดึงความสนใจจากเขา ต่อมาหลังจากร้านอาหารของเธอถูกโจมตีโดยกลุ่ม **By-X** เธอจึงตั้งใจฝึกฝนการต่อสู้อย่างจริงจังเพื่อปกป้องสิ่งที่เธอรัก

**Character Identity**

* นักสู้หญิงที่มีพลังสูง
* บุคลิกแข็งแรงและตรงไปตรงมา

***

## 5. Nicky

**Basic Profile**

| Attribute  | Value                     |
| ---------- | ------------------------- |
| Age        | 20                        |
| Gender     | Female                    |
| Occupation | Fashion Model / Detective |
| Hobby      | Inline Skating            |
| Blood Type | B                         |

**Character Background**

Nicky เป็นนักสืบที่ได้รับมอบหมายให้สืบสวนความลับของการแข่งขัน **FFC** ที่เกิดขึ้นเมื่อ 4 ปีก่อน ระหว่างการสืบสวน เธอถูกเปิดโปงตัวตนและตกอยู่ในอันตราย แต่ Wells ได้เข้ามาช่วยเหลือ เธอจึงเข้าร่วม Saints Association เพื่อสืบสวนเรื่องราวต่อไปจากภายในองค์กร

**Character Identity**

* นักสู้หญิงที่มีความสวยและความสามารถ
* มีบทบาทสำคัญในเนื้อเรื่องหลัก

***

## 6. Sera

**Basic Profile**

| Attribute  | Value   |
| ---------- | ------- |
| Age        | 19      |
| Gender     | Female  |
| Occupation | Student |
| Hobby      | Cosplay |
| Blood Type | O       |

**Character Background**

Sera เป็นพี่สาวของ Joony และลูกสาวของ Davark เธอเป็นคนใจดีและพยายามทำให้ครอบครัวกลับมาปรองดองกัน แม้ว่าเธอจะไม่ชอบการต่อสู้ แต่เธอกลับมีพรสวรรค์ด้านการต่อสู้สูงมากจากสายเลือดของพ่อ

**Character Identity**

* นักสู้หญิงบุคลิกสดใส
* เป็นตัวละครที่เชื่อมโยงความสัมพันธ์ของหลายตัวละคร
