# Street Class

### 1. Street Class (Striking Fighter)

Street เป็นสายการต่อสู้ที่เน้น

* การโจมตีระยะประชิด
* การใช้หมัดและเตะ
* การทำ Combo ต่อเนื่อง
* การ juggle ศัตรูให้ลอยกลางอากาศ

Street class ถูกออกแบบมาเพื่อ **สร้าง damage ต่อเนื่องผ่าน combo attacks** และควบคุมพื้นที่การต่อสู้ด้วยการโจมตีต่อเนื่อง

#### จุดเด่น

* Combo ยาว
* Damage ต่อเนื่อง
* เหมาะกับ PvP

#### จุดอ่อน

* ไม่มี Grab control
* ถ้าโดนจับจะเสียเปรียบ
