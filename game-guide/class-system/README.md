# 🤼 Class System

### Overview

ระบบ Class ในเกม **Zone4** ถูกออกแบบเป็น **Martial Arts Based Class System** ซึ่งใช้ศิลปะการต่อสู้จริงเป็นพื้นฐานของสไตล์การต่อสู้แต่ละอาชีพ

ผู้เล่นสามารถเลือก **Base Class** ก่อน และเมื่อเลเวลถึงระดับที่กำหนด จะสามารถพัฒนาไปสู่ **Advanced Class** ที่มีรูปแบบการต่อสู้เฉพาะตัว

ระบบนี้ทำให้เกมมีความหลากหลายทั้งด้าน

* Playstyle
* Combo Mechanics
* PvP Strategy
* Skill Expression

ในเกม Zone4 จะมี **2 Base Class หลัก**

1. Street (สายโจมตี)
2. Rush (สายจับทุ่ม)

และพัฒนาไปเป็น **8 Fighting Styles หลัก**
