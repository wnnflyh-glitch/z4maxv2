# Rush Class

### 2. Rush Class (Grappler Fighter)

Rush เป็นสายการต่อสู้ที่เน้น

* การจับ
* การล็อค
* การทุ่ม
* การควบคุมตำแหน่งคู่ต่อสู้

Rush class สามารถ **grab opponent แม้ขณะลอยกลางอากาศ** และสร้าง damage สูงจาก throw attacks

#### จุดเด่น

* Grab damage สูง
* Crowd control ดี
* ทำลาย combo ศัตรูได้

#### จุดอ่อน

* ความเร็วช้ากว่า
* combo สั้นกว่า
