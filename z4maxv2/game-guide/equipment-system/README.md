# 🎽 Equipment System

### 1. Overview

ระบบ **Equipment (อุปกรณ์สวมใส่)** ของ Zone4 เป็นระบบที่ใช้สำหรับ

* เพิ่ม **Combat Stat**
* เปลี่ยน **Appearance ของตัวละคร**
* สร้าง **Character Build**

ระบบนี้เป็น **Core Progression System** ของเกม โดยผู้เล่นสามารถ

* ใส่ไอเท็มหลายช่องพร้อมกัน
* สร้าง build ตามสไตล์การเล่น

Zone4 ใช้ระบบ

> **Stat-based Equipment Enhancement**

ซึ่งหมายความว่าไอเท็มทุกชิ้นจะเพิ่ม **ค่าพลังสเตตัส** ให้ตัวละคร

## 2. Equipment Slot System

ตัวละครสามารถสวมใส่อุปกรณ์หลายประเภท

ตัวอย่าง slot หลักในเกม

| Slot   | Description   |
| ------ | ------------- |
| Hair   | ทรงผม         |
| Face   | ใบหน้า        |
| Top    | เสื้อ         |
| Pants  | กางเกง        |
| Shoes  | รองเท้า       |
| Gloves | ถุงมือ        |
| Hat    | เครื่องประดับ |
| Back   | ไอเท็มหลัง    |
| Ring   | แหวน          |

อุปกรณ์แต่ละชิ้นมีผลต่อ

* appearance
* stat
