# Skill Upgrade System

## Overview

**Skill Enhancement System** เป็นระบบที่ให้ผู้เล่นเพิ่มประสิทธิภาพของ Skill ที่ครอบครองอยู่ โดยสามารถอัปเกรดระดับของ Skill จาก **Lv.0 → Lv.10**

การอัปเกรดจะเพิ่ม

* Damage ของ Skill
* Efficiency ของการโจมตี

ระบบนี้มี **Risk System** คือมีโอกาส **สำเร็จ / ล้มเหลว**

## Upgrade Resource

ระบบใช้ resource หลัก

| Resource             | Function         |
| -------------------- | ---------------- |
| Skill Upgrade Coupon | ใช้ในการ upgrade |
| ZEN                  | ค่า fee          |
| Zeed Blessing        | Token            |
