# Hidden Arcade

Hidden Arcade หรือที่ผู้เล่นเรียกว่า **“Joker”** เป็นโหมด PvE ลับของเกม Zone4 ซึ่งจะเปิดให้ผู้เล่นเข้าเล่นได้เมื่อทำผลงานใน **Normal Arcade** ได้ในระดับสูง

เงื่อนไขสำคัญคือ

> ผู้เล่นต้องเคลียร์ **Normal Arcade สำเร็จ** และทำ **เวลาได้ Rank S หรือสูงกว่า**

เมื่อทำเงื่อนไขนี้สำเร็จ ระบบจะ **การันตีการเข้าสู่ Hidden Arcade**

## Unlock Condition

### Core Requirement

ผู้เล่นต้องผ่านเงื่อนไข 2 อย่าง

| Requirement         | Description               |
| ------------------- | ------------------------- |
| Clear Normal Arcade | ผ่านด่านสุดท้ายของ Arcade |
| Rank Requirement    | ได้ S Rank หรือสูงกว่า    |

### Rank Calculation

Rank จะถูกคำนวณจาก

* Clear Time

#### Rank Example Model

```
RankScore = TimeScore
```

| Rank | Requirement |
| ---- | ----------- |
| F    | Fail        |
| C    | Clear Stage |
| B    | Normal      |
| A    | Fast        |
| S    | Very Fast   |

***

## Hidden Arcade Structure

Hidden Arcade เป็น **Special PvE Stage**

### Stage Characteristics

| Feature    | Description    |
| ---------- | -------------- |
| Stage Type | Boss Challenge |
| Enemy Type | Elite NPC      |
| Difficulty | Extreme        |
| Length     | Short          |
