# 👑 VIP System

VIP System เป็นระบบ **Premium Subscription Model**

ผู้เล่นสามารถซื้อ VIP เพื่อปลดล็อกสิทธิพิเศษทันที

#### คุณสมบัติหลักของระบบ

## VIP Activation

ผู้เล่นสามารถเปิดเมนู&#x20;

<figure><img src="../.gitbook/assets/VIP System.gif" alt=""><figcaption></figcaption></figure>

```
EVENT → VIP
```

จากนั้นระบบจะแสดงสถานะ

<figure><img src="../.gitbook/assets/image (85).png" alt="" width="563"><figcaption></figcaption></figure>

```
You are not a VIP member yet
```

<figure><img src="../.gitbook/assets/VIP 2.gif" alt=""><figcaption></figcaption></figure>

ผู้เล่นสามารถกด

```
Purchase
```

เพื่อซื้อ VIP

## VIP Privileges

เมื่อเปิดใช้งาน VIP ผู้เล่นจะได้รับสิทธิประโยชน์ดังนี้

***

### Stats Bonus

```
All Status +30
```

เพิ่มค่าสถานะตัวละครทั้งหมด

<figure><img src="../.gitbook/assets/image (87).png" alt=""><figcaption></figcaption></figure>

### EXP / Zen Bonus

```
EXP / ZEN Bonus +10%
```

ผู้เล่นจะได้รับ

| Resource | Bonus |
| -------- | ----- |
| EXP      | +10%  |
| Zen      | +10%  |

### Special Storage

```
Special Storage
```

ผู้เล่น VIP จะได้รับ

**ช่องเก็บของพิเศษ**

### NPC Discount

```
10% Special Discount NPC Yuki
```

ผู้เล่น VIP จะได้รับ

```
10% Discount
```

เมื่อซื้อของจาก NPC Yuki

### Daily Potion

```
HP/SP Potion Everyday 50ea
```

ผู้เล่น VIP จะได้รับ

| Item      | Amount |
| --------- | ------ |
| HP Potion | 50     |
| SP Potion | 50     |
